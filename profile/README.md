# Altumptic

**Security research, done in the open.**

An independent lab studying how the software that guards keys and servers
breaks under attack — and building open tools that don’t.

[Website](https://altumptic.com) · [Community](https://github.com/Altumptic/community/discussions) · [Research log](https://altumptic.com/#register)

## Tools

| | Project | What it is |
| ---: | --- | --- |
| **ALT-11** | [**paranoia**](https://github.com/Altumptic/paranoia) | Open, local-first reverse engineering — PE / ELF / Mach-O, graphs, pseudocode. Rust engine, no network. |
| **ALT-02** | [**LemonSees**](https://github.com/Altumptic/LemonSees) | Agentless SOC & GRC over SSH — SIEM, FIM, MITRE ATT&CK, compliance. Nothing installed on servers. |
