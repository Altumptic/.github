# Security Policy — Altumptic

## Reporting a Vulnerability

If you discover a security vulnerability in any Altumptic project,
please report it responsibly:

- **GitHub**: Use [GitHub Security Advisories](https://github.com/Altumptic/.github/security/advisories/new)
- **Twitter/X**: [@thefear078](https://x.com/thefear078)

**Do NOT** open public issues for security vulnerabilities.

## Supported Versions

Only the latest release of each project is supported with security updates.

## Response Timeline

| Step | Timeline |
|------|----------|
| Acknowledgment | 48 hours |
| Initial Assessment | 7 days |
| Patch Release | 90 days |

## Security Best Practices

- All commits must be signed (`--gpg-sign` or `--signoff`).
- Branch protection rules are enforced on all production branches.
- PR reviews are required before merging.
- Force pushes and branch deletions are blocked.
- Dependabot alerts and secret scanning are enabled.
